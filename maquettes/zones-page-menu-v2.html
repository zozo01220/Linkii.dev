Décisions

  1. Validé Place dans le menu : après « Aires de gestion ».
  2. Validé Visibilité : le menu Zones s'affiche à qui a le droit « Gérer les zones ».
  3. Validé Écrans dans la fenêtre de création : retirés.
  4. Validé Liens « Gérer les zones… » : ils mènent à la page Zones (filtre Zone, actions de zone).
  5. Validé Mode simple : l'adresse zones affiche « Disponible en mode expert ».
  6. Ajouté Aire de gestion parente en colonne, et filtre par aire en haut de la page (« Toutes les aires » par défaut).
  7. Ajouté Aire dans la fenêtre : champ obligatoire, préremplie avec le filtre. Choix de ma part : à confirmer.
