Code du menu technicien, défini par client

Aujourd'hui chaque boîtier garde son propre code (9999 par défaut, modifiable sur place). Proposition : un code unique par organisation, réglé dans Réglages, que tous ses écrans appliquent.

1 · Réglages › Écrans — nouvelle carte « Menu technicien »

Menu technicien des écrans

Code demandé sur les boîtiers Android après 5 appuis sur OK (ou 5 touchers en haut à droite). Il s'applique à tous les écrans de l'organisation.

Protéger le menu par un codeSans code, n'importe qui devant l'écran peut changer de serveur ou désappairer.

Dernière modification le 17 oct. 2026 par L. Prieur

Autoriser un code propre à un appareilLe technicien peut encore définir un autre code depuis le menu (il remplace celui-ci sur cet appareil).
Notes
  • Visible seulement avec le droit « Réglages » (niveaux de droits).
  • Tant que le code n'a pas été défini : bandeau orange « Code par défaut 9999 sur vos écrans » + bouton « Définir un code ».
  • Nouvelle organisation : un code aléatoire est généré à la création (plus de 9999 partout).
