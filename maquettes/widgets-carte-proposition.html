Carte widget — proposition

Même langage que la carte d'intégration validée (§94-95) : un en-tête (icône, nom, bouton i, menu ⋮), une description courte, un pied de carte qui donne l'état. L'interrupteur disparaît au profit d'une pastille et d'une entrée « Activer / Désactiver » dans le menu.

Ce qui change

  • Interrupteur retiré. L'état est une pastille (Actif vert, Inactif gris) ; « Désactiver » est dans le menu ⋮, comme pour les intégrations.
  • Aperçu plus bas (104 px au lieu d'un cadre de 118 px) : la carte tient mieux dans la grille.
  • Bouton i : ouvre le détail du widget (même tiroir que les intégrations). Le détail reprend les paramètres et la liste des écrans.
  • Pied de carte : l'état à gauche, le nombre d'écrans à droite (« Aucun écran » devient un chiffre quand il y en a). Le libellé « Aucun écran » sous le nom disparaît.
  • Désactivé : aperçu et icône grisés, fond rayé, pied gris : repérable d'un coup d'œil.
  • Pas de description en double : la description reste sur deux lignes au plus.

Vue Liste : même principe (nom, état, nombre d'écrans, ⋮). Non codé. Les textes et icônes des widgets sont ceux de l'écran actuel.
