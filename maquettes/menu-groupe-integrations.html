Groupe « Intégrations » dans le menu

Menu de gauche : un groupe repliable après un trait

  • Sous Programmations, séparé par un trait ; mode Expert seulement.
  • Une entrée par intégration qui a une page de paramétrage (aujourd'hui : Plans du bâtiment pour Home Assistant). Le groupe n'existe pas sans elles.
  • Replié par défaut ; s'ouvre tout seul quand on est sur une de ses pages. Une pastille rouge apparaît sur le groupe si une entrée a un problème.
  • Le catalogue et les comptes restent dans l'onglet Intégrations de Contenus.
