Refonte du menu

Menu : le groupe « Applications » remplace « Intégrations »

  • Écrans, Listes de lecture, Contenus, Programmations restent en haut. Contenus ne garde que Médiathèque, Compositions et Widgets.
  • Applications : une entrée par application installée et affichée dans le menu. Chaque nouvelle installation s'ajoute à la fin du groupe. Le groupe se replie et se déplie, et une pastille rouge apparaît si une application a un problème.
  • En bas du groupe : Store (ouvre le tiroir existant) et Gérer mes applications.
  • Le groupe est visible aussi en mode simple : c'est la vitrine du produit.

Page d'une application : tout ce qui la concerne au même endroit

  • Contenus : ce qui a été créé avec elle, plus un bouton pour en créer un autre.
  • Configuration : les réglages propres à l'application (clé, unités, connexion requise…).
  • Infos : éditeur, version, plan requis, écrans qui la diffusent. Désinstaller est en haut à droite.

« Gérer mes applications » : la liste complète, y compris celles absentes du menu

  • Choisir ce qui apparaît dans le menu (interrupteur) et dans quel ordre (poignée ⋮⋮). Les 8 applications de base, installées d'office (PDF, Page web…), ne sont pas dans le menu par défaut : on les trouve ici.
  • Voir l'état de toutes les applications d'un coup d'œil : en erreur, mise à jour disponible, plan requis.
  • Désinstaller (une application de base peut seulement être masquée). Lien vers le Store.
  • Sans cette page, le menu grossirait à chaque installation et les applications de base seraient introuvables.

Réglages : Connexions et Développeurs dans une section « Avancé »

  • Connexions : comptes Google/Microsoft/Dropbox, Home Assistant, bases SQL, API, fichiers, relais (ex-Comptes connectés et Sources de données).
  • Développeurs : Clés, Webhooks, Journal (ex-API et webhooks).
  • La section Avancé n'existe qu'en mode expert. Passez en mode simple avec le bouton en haut pour la voir disparaître.

Connexions › Comptes : un compte par fournisseur, partagé par toutes les applications

  • D'où viennent les comptes ? Surtout de l'installation d'une application : l'assistant fait se connecter chez le fournisseur, et le compte apparaît ici automatiquement. On peut aussi en connecter un d'avance avec « + Connecter un compte ».
  • Nouvelle application, compte déjà connecté (par exemple Google Slides alors que Google Drive l'est déjà) : pas de doublon. On demande seulement l'accès en plus sur le même compte.
  • Gérer un compte (un clic sur la ligne) : voir les accès accordés, en ajouter ou en retirer, voir quelles applications l'utilisent, le reconnecter, changer de compte, le déconnecter en voyant l'impact.
  • Les sous-onglets Données (API, fichiers, SQL) et Relais reprennent les actuelles Sources de données.
