Maquette — 10 modèles « jeux de données » à valider avant de coder. Les chiffres sont fictifs. Clique une vignette pour voir les colonnes attendues.

Modèles › Jeux de données

Chaque modèle se remplit tout seul : on choisit un jeu de données (API, fichier, liste reliée, base SQL ou envoi direct) et on relie ses colonnes. L'affichage se met à jour à chaque nouvelle lecture. Aucun texte à retaper.

Où ils apparaissent : dans Compositions › Modèles › Galerie, un nouveau filtre « Jeux de données » (mode expert seulement, comme Données et Graphiques). Au choix du modèle, un assistant demande le jeu de données puis relie les colonnes ; sans jeu de données, une ligne d'exemples est proposée pour essayer. Tout reste modifiable, et rien n'est enregistré avant « Enregistrer ».
