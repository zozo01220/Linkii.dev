Maquette — Aperçu média en grande fenêtre, avec le vrai CSS de l'app ← → naviguer · I infos · Échap fermer

Ce qui change par rapport au tiroir

  • Fenêtre centrée de 1360 px max (≈ 95 % de l'écran), au lieu de 400 px.
  • Le média est affiché en entier, sans rognage, sur le fond sombre de l'app.
  • Suppression : icône corbeille en haut, à côté de ⓘ, avec une confirmation qui rappelle où le média sert.
  • Diaporama : les flèches tournent les pages, les miniatures du bas deviennent les pages, ▶ lance le défilement, et ‹ 3 / 8 › dans l'en-tête passe au média voisin.
  • Par défaut, la colonne d'infos est masquée : le média a toute la place. ⓘ (ou I) l'ouvre.
  • Partager et Télécharger sont dans la pastille sous le média ; la colonne ne garde que Ranger…, Autre aire… et Supprimer.
  • Renommer : clic sur le titre (ou le crayon au survol), Entrée enregistre, Échap annule — comme une liste de lecture.
  • Colonne d'infos à droite : mêmes boîtes (partage, description IA, utilisé dans) ; elle se replie avec le bouton ⓘ.
  • Outils dans une pastille en bas (zoom, pivoter, plein écran), comme la pastille de rotation des cartes.
  • Fil de vignettes pour passer au voisin. Sur mobile : le média en haut, les infos dessous.
