Dans la liste, le nom a sa propre colonne, comme les médias. Le mot « pages » remplace « diapositives » pour GDocs et PDF. La taille est celle de toutes les images de la présentation.

Comportements communs

  • Clic sur la carte (dans les trois vues) : ouvre le tiroir de la présentation (informations, diapositives, « Convertir en image », utilisation).
  • Recherche et filtres : le filtre « Présentations » (et les sources PowerPoint / GSlides / GDocs / PDF / Canva) s'ajoute aux sources existantes ; « Non utilisés » inclut les présentations orange ; le compteur des médias compte une présentation pour 1.
  • Sélection, glisser-déposer, dossiers : comme un média (une présentation se range dans un dossier, se partage, se supprime d'un coup).
  • Menu ⋮ : Ouvrir, Mettre à jour, Ranger…, Partager…, Supprimer (inactif tant qu'un contenu l'utilise).

Deux points à confirmer

PowerPoint : vous n'avez pas donné d'acronyme pour la pastille d'une présentation PowerPoint (OneDrive est le nom du Drive, pas du format). J'ai mis « PowerPoint » ; vous pouvez préférer « OneDrive » comme pour les autres médias venant de OneDrive.

Légende sous la carte : je l'ai retirée dans la vue Cartes, comme demandé ; le nom reste dans l'aperçu.
