Intégrations

Les sources de contenus proposées dans vos listes de lecture, et les comptes qui leur donnent accès.

Ce qui change
  • Dans « Gérer » d'un Drive, « Choisir un dossier… » ouvre un sélecteur. On y parcourt les dossiers du compte connecté sans copier de lien. Coller un lien de partage reste possible (« ou coller un lien »).
  • Le sélecteur affiche les images et vidéos du dossier, c'est-à-dire ce que les écrans montreront. Les autres fichiers (PDF, documents) sont seulement comptés.
  • Option « Inclure les sous-dossiers » au moment de l'ajout, modifiable ensuite dans le menu ⋯ du dossier. Tous les niveaux sont parcourus, avec au plus 300 fichiers au total.
  • Pas de nouvelle autorisation : la lecture seule déjà accordée (Drive, Files.Read.All) suffit pour parcourir.
À trancher
  • SharePoint : pour lister les sites, il faut l'accès « Sites.Read.All », donc reconnecter le compte Microsoft. Dans cette maquette, on colle le lien d'une bibliothèque, et les dossiers SharePoint partagés avec le compte apparaissent dans « Partagés avec moi ».
  • Avec les sous-dossiers, l'ordre « par nom » trie par chemin (2025/… avant 2026/…). C'est la proposition ; l'autre choix serait de trier par nom de fichier seul.
  • Profondeur : tous les niveaux (proposé) ou seulement le premier niveau ?
