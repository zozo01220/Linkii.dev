Ce qui change

  • « Options avancées » devient « Paramètres de l'écran », avec deux sections : Affichage (existant : matériel, résolution, miroir) et Appareil (nouveau).
  • Démarrage automatique : oui par défaut, pour Windows et Android TV.
  • Afficher dans une fenêtre (interrupteur, non par défaut) et Moniteur : seulement pour un écran Windows ; le moniteur n'apparaît que si le PC en a plusieurs.
  • Ajouter un écran sur ce PC : dans le menu ⋮ d'un écran Windows ; le nouvel écran arrive déjà appairé. Le supprimer ferme sa fenêtre sur le PC.
  • Les réglages « Appareil » s'appliquent dès l'enregistrement, sans publier.
  • Aucune commande ni ligne de commande sur le PC : installeur, démarrage, appairage par code, le reste vient du back-office.
