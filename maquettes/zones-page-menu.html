Après

Écrans

Un seul bouton, sans menu. Les zones se gèrent dans le menu Zones. Le filtre « Zone ▾ » garde un lien « Gérer les zones… » vers la page.

Points à confirmer avant de coder

  1. Place dans le menu : après « Aires de gestion », avant « Membres » (bloc administration, mode expert). Alternative : juste après « Écrans ».
  2. Qui voit le menu : aujourd'hui le bloc est réservé aux administrateurs ; les zones se gèrent selon le droit « Gérer les zones » du niveau. Proposé : afficher Zones à qui a ce droit.
  3. Une aire à la fois : la page suit l'aire ouverte (sélecteur d'aire de la barre du haut), comme l'écran Écrans.
  4. Écrans dans la fenêtre de création : ajout nouveau (aujourd'hui on crée une zone vide, puis on déplace les écrans). Retirer la liste si vous préférez garder le comportement actuel.
  5. Mode simple : l'adresse directe zones affichera « Disponible en mode expert », comme Membres et Aires.
  6. Ce qui disparaît : l'entrée « Gérer les zones » du menu « + Ajouter ». Les liens « Gérer les zones… » du filtre Zone et des actions de zone deviennent des liens vers la page.
