Médiathèque Intégrations
Proposition — La page Intégrations passe à deux onglets :
  • Mes intégrations : ce que l'organisation utilise. Les 8 intégrations de base y sont déjà activées dès la création du compte (plans Base et Growth), désactivables avec l'interrupteur.
  • Intégrations Store : toutes les autres, chacune avec un gros bouton Utiliser. Il ouvre le tiroir de configuration ; que le test réussisse ou non, l'intégration passe dans Mes intégrations (en rouge si la config est erronée, avec un bouton Corriger).
  • Dans les deux onglets : groupes par catégorie, filtrables par boutons.
