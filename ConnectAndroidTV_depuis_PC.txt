Il y a deux étapes : activer le débogage sur le boîtier, puis y installer l’APK.

1. Préparer le boîtier Android TV

Ouvrez Paramètres > Système > À propos et appuyez 7 fois sur Build (ou « Version du build »). Le mode développeur s’active.
Ouvrez Paramètres > Système > Options pour les développeurs et activez Débogage USB. Selon le modèle, vous aurez aussi Débogage ADB ou Débogage réseau.
Branchez le boîtier sur le même réseau que votre PC. La plupart des boîtiers Android TV et des Fire TV n’ont pas de port USB de débogage, donc on passe par le Wi-Fi.

2. Se connecter depuis le PC (cherchez l’adresse IP du boîtier dans Paramètres > Réseau)

~/AppData/Local/Android/Sdk/platform-tools/adb.exe connect 192.168.x.x:5555

Le boîtier affiche une fenêtre « Autoriser le débogage ? ». Acceptez-la, en cochant « Toujours autoriser ». Vérifiez ensuite la connexion :

~/AppData/Local/Android/Sdk/platform-tools/adb.exe devices

Avec Android 11 ou plus récent, utilisez Débogage sans fil et adb pair si connect échoue.

3. Installer l’APK

Pour installer l’APK déjà compilé :

~/AppData/Local/Android/Sdk/platform-tools/adb.exe -s 192.168.x.x:5555 install -r Linkii.Android/app/build/outputs/apk/debug/app-debug.apk

Pour recompiler et installer avec Gradle, ajoutez l’adresse du serveur. Sur un vrai boîtier, 10.0.2.2 ne marche pas, il faut une adresse HTTPS ou l’IP du PC :

cd Linkii.Android
JAVA_HOME="/c/Program Files/Android/Android Studio/jbr" ./gradlew :app:installDebug -PserverUrl=https://linkii.duckdns.org

Si plusieurs appareils sont connectés (émulateur compris), Gradle installera sur tous. Déconnectez l’émulateur avant, ou utilisez -s avec adb.

4. Lancer l’app

Elle est dans la liste des applications du boîtier, sous Linkii Player. Elle peut être sous « Autres applications ».
Pour la lancer depuis le PC : adb -s 192.168.x.x:5555 shell monkey -p ch.linkii.player -c android.intent.category.LAUNCHER 1.
Elle affiche un code à 6 chiffres. Saisissez-le dans le back-office pour appairer l’écran.

Pour un test en conditions réelles

Utilisez une adresse en HTTPS, sinon il n’y a pas de mode hors ligne.
Dans le menu technicien, vous pouvez activer le démarrage automatique. Définir Linkii comme écran d’accueil est plus fiable.

Sur un Fire TV, les options développeur se trouvent dans Ma Fire TV > À propos, avec 7 appuis sur le nom de l’appareil, puis Débogage ADB et Applications de sources inconnues.
